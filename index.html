⚡ Poly WAV メーカー

ZOOM H6e などのパラWAV（ZOOM0001_Tr1.WAV / _Tr2.WAV / _LR.WAV …）を 1つの Polyphonic WAV に結合します。波形はバイト単位でそのままインターリーブするため 32-bit float / 24-bit / 16-bit を完全維持（再量子化なし）。bext / iXML も引き継ぎます。 ファイルは端末の外に送信されません（このページ内だけで処理します）。

ここにフォルダ / WAVをドロップ（Mac / Windows / スマホ）
複数のフォルダを投げても、フォルダごとに1ファイルずつ別々に出力します

ファイルを選んでください。

使い方・プライバシーポリシー

使い方

  1. WAVファイルをまとめて選ぶか、テイクフォルダを選んでください（この枠へのドラッグ＆ドロップでもOK）。
  2. 必要に応じてオプション（「*_Mix.WAV（2MIX）も含める」「LR / XY を先頭に置く」）を設定します。
  3. 「Poly WAV に変換する」を押すと、フォルダごとに *_POLY.wav が作られます。表示された保存リンクからダウンロードしてください。

入力ファイルは読み取りのみで、変更されません。巨大なテイク（数GB）はメモリ不足になることがあります。その場合は Python 版（poly_wav.py）をお使いください。

プライバシーポリシー

  • 選択した音声ファイルは、すべてお使いの端末のブラウザ内だけで処理されます。ファイルが外部のサーバーへ送信されることはありません。
  • このページは、処理のための通信を行いません。アクセス解析・広告・Cookie による追跡もなく、設定や履歴が保存されることもありません。
  • Python 版も端末内だけで動作し、外部と通信しません。
